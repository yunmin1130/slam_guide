# CURRICULUM

20주 핵심 경로. 주당 약 5시간 기준이며, 육아로 밀리면 한 주를 2주로 늘려도 된다. 실제 기간은 5~6개월로 본다.

**12주차(미니 VO 완성)부터 이직 지원을 시작**하고, 13~20주차는 지원과 병행한다.

## 범례

- **데모 ✅**: 인터랙티브 데모를 만드는 주차 (핵심 7개)
- **손코딩**: `core/mine`에 직접 구현할 함수
- **LA 박스**: 이번 주에 필요한 선형대수 개념
- **🤖 JetBot**: JetBot 실데이터를 쓰는 주차

## 주차별 상세

### 1주차 — 플랫폼 뼈대 + 선형대수 ①
- Astro 세팅, 레슨 템플릿, 공용 3D 뷰어, Gist 저장 계층
- **LA1 레슨 하나를 끝까지 완성**하고 이를 템플릿으로 삼는다.
- 반대칭 행렬(`skew`)은 이후 회전·Lie·에피폴라에 계속 나오므로 1주차에 확실히 잡는다.

### 2주차 — 선형대수 ②
- 8점 알고리즘, 삼각측량, PnP, 궤적 정렬이 거의 다 **"SVD로 Ax=0 풀기"**다. 가장 중요한 주.
- 필요하면 2주로 늘린다.

### 4주차 — 카메라 모델
- 카메라 엔진 경험이 가장 빛나는 주차.
- JetBot 카메라(IMX219-160)는 160° 광각이라 핀홀 모델로 맞지 않는다. 어안 모델과 재투영 오차를 비교한다.

### 11~12주차 — 미니 VO
- 이직 지원 시작 시점의 핵심 결과물.
- 가능하면 C++로도 구현해 C++ 실력을 보완한다.
- 정답 궤적이 없는 JetBot 데이터는 출발점 복귀 오차 또는 줄자로 잰 사각형 경로로 평가한다.

### 16~20주차 — 캡스톤
주제: **카메라 특성이 Visual Odometry 정확도에 주는 영향**

- 같은 경로를 **속도만 바꿔 주행** → 롤링셔터 왜곡과 모션 블러의 영향
- **조명 조건 변경** (불 켜고 끄기, 창가 역광) → 자동 노출 변화가 특징점 추적에 주는 영향
- (ROS 버전) **라이다 SLAM 결과를 기준 궤적**으로 삼아 비주얼 결과와 비교
- 결과는 인터랙티브 리포트 레슨으로 정리한다.
- 회사 코드나 내부 데이터는 절대 쓰지 않는다. 공개 데이터셋과 직접 수집한 데이터만 사용한다.
